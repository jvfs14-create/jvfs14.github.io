Seção 3 — Glossário de termos técnicos

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Responsável pelo estilo visual das páginas.
JavaScript
JS
Linguagem de programação da web.
DOM
Estrutura em árvore do HTML.
API
Interface que permite comunicação entre sistemas.
